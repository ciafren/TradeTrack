# TradeTrack Journal

Zero-install mobile-friendly trading journal for GitHub + Vercel.

## Deploy
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js`, and `vercel.json`.
3. In Vercel choose **Add New > Project** and import the repository.
4. Leave Framework Preset as **Other** and deploy.

## Included
- Screenshot upload and trade details
- Automatic green/red P&L status
- Calm, Overtrade, Tilt, and FOMO psychology status
- Calendar plotting daily trade count and P/L
- Daily, weekly, and monthly totals
- Prop-firm NEW and RESET cost tracking with separate totals
- Payout entries and payout total

## Storage
Entries currently use browser localStorage. They remain on the same browser/device, but do not sync across devices. Cloud login, database, and image storage are appropriate for the next version.
